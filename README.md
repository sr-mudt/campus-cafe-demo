# Campus Café: before/after teaching demo (SE-501)

The same fictional café website, built twice with **Astro + Tailwind CSS**:

| Path | Version |
|------|---------|
| `/` | Neutral landing page (links to both versions) |
| `/before/` | Version **Before** |
| `/after/` | Version **After** |

**Your task (SE-501):** find out what differs between the two versions, and why it matters. Everything is fictional and harmless; nothing is sent anywhere.

## Run locally

You need **Git** and **Node.js 22.12 or newer** (`node -v`).

```bash
git clone https://github.com/rathmayers/campus-cafe-demo.git
cd campus-cafe-demo
npm install
npm run build      # first run also generates the images (~10 s)
npm run preview    # → http://localhost:4321
```

For exploring and changing the code use `npm run dev` instead (live reload). For Lighthouse measurements always use `build` + `preview`: the dev server is not optimised.

Images are **generated by code** at build time (`scripts/generate-images.mjs`) so the repository stays small and there are no copyright issues. Regenerate with `npm run images`.

## Deploy

### Vercel

Import the repository (framework: Astro, build command `npm run build`). Settings for Vercel are in `vercel.json`.

### GitHub Pages

1. Push to a GitHub repository (branch `main`).
2. Repository → **Settings → Pages → Source: GitHub Actions**.
3. The workflow `.github/workflows/deploy-pages.yml` builds with `SITE` and `BASE` set automatically, so the site works under `https://<user>.github.io/<repo>/`.
